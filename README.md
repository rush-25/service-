# Renter Car

This project consists of a backend Node.js server and a frontend React application (powered by Vite). 
Follow the instructions below to run both concurrently.

## Prerequisites

Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

## Running the Backend

The backend server is located in the root directory.

1. Open a terminal in the root directory.
2. Install the backend dependencies (only needed once):
   ```bash
   npm install
   ```
3. Start the backend development server:
   ```bash
   npm run dev
   ```

## Running the Frontend

The frontend application is located in the `client` directory.

1. Open a **new** terminal and navigate to the `client` directory:
   ```bash
   cd client
   ```
2. Install the frontend dependencies (only needed once):
   ```bash
   npm install
   ```
3. Start the Vite development server:
   ```bash
   npm run dev
   ```
